# Negative Constraints — Generic Default
# ─────────────────────────────────────────────────────────────────────────────
# Niche-neutral hard exclusions for StoryFrame Studio image generation.
# Loaded automatically when this file is present alongside images.txt in the
# same preset folder.
# ─────────────────────────────────────────────────────────────────────────────

no readable text anywhere in the image
no subtitles
no captions
no logos
no watermarks
no signs with legible letters
no labels or packaging text
no poster text
no writing on walls or surfaces
no graffiti text
no UI text, menus, buttons, or HUD overlays
no cartoon style
no illustration style
no anime style
no extra people not mentioned in narration
no close-up portraits
no headshots
no tight face crops
no modern digital UI elements or screens showing menus
if text-bearing objects appear (books, signs, screens, product packaging),
keep any text blurred, turned away, obscured, or completely unreadable
